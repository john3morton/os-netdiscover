# Security Policy

## Supported versions

Please report issues against the latest release on `main` (see `Makefile` `PLUGIN_VERSION` and [CHANGELOG.md](CHANGELOG.md)).

## Reporting a vulnerability

Email **john3.networking@gmail.com** with a description of the issue, affected version, and reproduction steps if possible.

Do not open a public GitHub issue for sensitive vulnerability details until a fix is available or the maintainer confirms disclosure is OK.

You can expect an acknowledgment when the report is received; timelines vary with severity and complexity.
